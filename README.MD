# Node.js File Upload

A simple file upload application built with Node.js, Express, Multer, and EJS.

## Features

- Upload files through an HTML form.
- Handle file uploads using Multer.
- Store uploaded files locally.
- Display the uploaded filename after a successful upload.

## Technologies Used

- Node.js
- Express.js
- Multer
- EJS

## Installation

1. Clone this repository.
2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the server using the start command configured in `package.json`, or run:

   ```bash
   node index.js
   ```

4. Open `http://localhost:8000` in your browser.

## Learning Goals

This project helped me practice Express routes, middleware, file uploads, and server-side rendering with EJS.
